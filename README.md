## 📖 About

Personal portfolio built with **Angular 19** showcasing my skills, experience and projects as a Full Stack Developer specialized in Angular & Spring Boot fintech platforms.

---

## ✨ Features

- 🎨 **4 color themes** — Purple Night, Ocean Blue, Rose Gold, Forest
- 🌍 **Bilingual** — English / French language switcher
- ⚡ **Scroll animations** — elements animate on scroll
- 📱 **Fully responsive** — optimized for mobile and desktop
- 💬 **Contact form** — powered by EmailJS
- 🎬 **Project demos** — YouTube video integration with zoom on screenshots
- 🔤 **Typewriter effect** — animated role titles in the hero section
- 📄 **CV download** — direct download from floating bar

## 🚀 Getting Started

### Prerequisites

- Node.js 20.15.0
- Angular CLI 19.2.26

### Installation

```bash
# Clone the repo
git clone https://github.com/Ikram-Boussif/ikram-boussif-portfolio.git

# Navigate to project
cd ikram-boussif-portfolio

# Install dependencies
npm install

# Start development server
ng serve
```

Open `http://localhost:4200` in your browser.

### Build for production

```bash
ng build
```
